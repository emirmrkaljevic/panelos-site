Windows blocked PanelOS / SmartScreen

PanelOS is not code-signed yet, so Windows may show a SmartScreen warning the first time you run the installer. That is expected for a new independent app.

What to do

  1. Download only from the official PanelOS site (or the link we send you).
  2. If Windows says the app is unrecognized, choose More info, then Run anyway.
  3. Finish the installer as usual. Pro buyers use the same Setup.exe and unlock with their license key in Settings.

Once a code-signing certificate is in place, this warning goes away. Until then, stick to downloads from the site so you know the file is the real one.

Smart App Control blocked it or the file vanished

  • Windows Smart App Control blocks new apps that aren't signed yet, and PanelOS isn't signed yet. That doesn't mean it's malware.
  • Fix: open Windows Security → App & browser control → Smart App Control, set it to Off, then run the installer again. After installing, you can turn it back on there.
  • If the file was removed, go to Windows Security → Protection history, choose Restore, then download it again. Still stuck? Contact us for help or a refund.
