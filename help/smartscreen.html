Windows blocked PanelOS / SmartScreen

PanelOS is not code-signed yet, so Windows may show a SmartScreen warning the first time you run the installer. That is expected for a new independent app.

What to do

  1. Download only from the official PanelOS site (or the link we send you).
  2. If Windows says the app is unrecognized, choose More info, then Run anyway.
  3. Finish the installer as usual. Pro buyers use the same Setup.exe and unlock with their license key in Settings.

Once a code-signing certificate is in place, this warning goes away. Until then, stick to downloads from the site so you know the file is the real one.

Smart App Control blocked it or the file vanished

  • Windows Smart App Control blocks new apps that aren't signed yet, and PanelOS isn't signed yet. That doesn't mean it's malware.
  • Fix: open Windows Security → App & browser control → Smart App Control, set it to Off, then run the installer again.
  • Keep it Off while you use PanelOS. Smart App Control checks apps every time they start, not only when you install them, so if you switch it back On, Windows will block PanelOS again at startup until the app is signed.
  • Prefer to keep Smart App Control On? Then PanelOS can't run on that PC for now. That's why the free Lite version exists: try it first, and if a Pro purchase can't run because of this, contact us for a refund.
  • Not sure if it's on? Most PCs upgraded from Windows 10 or older Windows 11 versions have it Off already, so you'll only see the SmartScreen warning above.
  • If the file was removed, go to Windows Security → Protection history, choose Restore, then download it again. Still stuck? Contact us.
