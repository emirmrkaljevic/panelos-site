Which 3.5-inch USB screens work

PanelOS is a Windows app for the small 3.5-inch USB screens people put inside or on top of a PC case. Many of these screens look alike from the outside, so check the USB Hardware Id before you buy Pro.

Check your screen in two minutes

  1. Plug the screen into a USB port on the PC (not an unpowered hub for this test).
  2. Open Device Manager (right-click Start, then Device Manager).
  3. Find the new device, usually under Ports (COM & LPT) or Other devices, and open Properties.
  4. On the Details tab, pick Hardware Ids. Look for VID_1A86&PID_5722.

If you see 1A86:5722, PanelOS supports it. Install the free Lite version first: if Classic shows up on the screen, every Pro theme will too.

What PanelOS draws

  • 480×320 in landscape and 320×480 in portrait; switch from the tray menu.
  • CPU and GPU temperature and watts, plus RAM, VRAM and fan speed.
  • Now playing from Spotify (Pro), read from Windows, with no Spotify login.

Other sizes and other Hardware Ids

Other screen sizes are experimental for now. If yours shows a different Hardware Id, send it with the contact form before buying, and you'll get a straight answer on whether it works.

Lite is free, Pro is €14.99 once. Refund if it doesn't work with your panel and can't be fixed within 7 days.
