CPU temperature shows 0

The panel still runs. Only the sensor values that need elevated access read as zero.

  1. Re-run the installer and accept the admin step, or start PanelOS once as administrator.
  2. Some boards need the chipset / sensor stack from the motherboard maker before package temp and fans appear.
  3. GPU temp and load usually work without that; CPU and fan are the ones that go quiet.

If everything else looks fine and only CPU stays at 0 after admin + drivers, send your CPU model through the contact form.
