Device not connected

If the tray says the panel is missing, or the screen stays black:

  1. Unplug the panel, wait a few seconds, plug it back into a different USB port on the PC.
  2. Check Device Manager → the panel → Properties → Details → Hardware Ids. You want VID_1A86&PID_5722.
  3. Avoid unpowered hubs and long cheap extension cables for the first test.
  4. Quit PanelOS from the tray, open it again, then pick a theme once more.
  5. Power-cycle the panel (unplug USB) if only a strip of the image appears.
