Setup

Windows 10 or 11, 64-bit. Confirmed panels: 3.5″ USB with hardware id VID_1A86&PID_5722. Other sizes are experimental.

  1. Plug the panel into a USB port on the PC (not a passive hub if you can help it).
  2. Run PanelOS-Setup.exe. Allow the one-time admin step so temperatures and fans can read.
  3. Open the tray icon → Theme. Lite stays on Classic; Pro unlocks every theme.
  4. Optional: Settings → start with Windows (short delay so USB is ready).

Updates: run the new installer over the old one. Settings stay. Pro covers every 1.x update.

Windows may warn about an unsigned installer (SmartScreen). That is expected until code signing is in place — use “More info” → Run anyway if you trust the download from this site.
